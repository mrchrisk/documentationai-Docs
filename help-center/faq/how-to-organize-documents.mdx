## Overview

Use spaces and tags to manage documents in BosOn.

## Steps

1. Create a new Space for your project or team.
2. Inside a Space, add Folders and Subfolders.
3. Use tags to label documents by topic or status.
4. Search by tag, folder, or document name anytime.

## Tip

Move documents between spaces as projects evolve for flexible organization.
