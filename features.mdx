## Overview

BosOn helps you organize AI-generated images and videos with powerful tools for storage, workflow management, and discovery. You can create boards, assign statuses, search visually or by tags, and use the Studio for editing. Follow the slogan: Make it. Keep it. Find it. Post it.

<Callout kind="info">
  All features are available in early access. Request access at [getboson.app](https://getboson.app/#access).
</Callout>

## Library and Boards Management

The Library stores all your AI-generated content in one place. You create boards to group items by project, like "Aura launch" or "Spring drop".

## Search by Content and Tags

Find items instantly with visual search or tags. No more digging through folders.

<Tabs>
  <Tab title="Visual Search" icon="search">
    Upload a reference image to find similar content.
    
    ```javascript
    // Example API call for visual search
    const results = await fetch('https://api.example.com/search/visual', {
      method: 'POST',
      body: formDataWithImage
    });
    ```
  </Tab>
  <Tab title="Tag Search" icon="tag">
    Query by tags like "16:9", "portrait", or "campaign".
    
    ````javascript
    // Search by tags
    const items = await boson.search({
      tags: ['live', 'meta'],
      query: 'aura'
    });
    console.log(items); // Returns matching assets
    ````
  </Tab>
  <Tab title="Advanced Filters" icon="filter">
    Combine status, board, and date filters.
  </Tab>
</Tabs>

<Callout kind="tip">
  Visual search works best with high-contrast AI-generated images for accurate matches.
</Callout>

<Expandable title="Basic Editing" default-open="true">
