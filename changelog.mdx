## Recent Updates

Stay informed about the latest BosOn releases. You can find detailed release notes for each version below, including new features, improvements, bug fixes, and any breaking changes.

<Update label="2024-12-15" description="v1.2.0" tags={["feature", "improvement", "bugfix"]}>

## New Features

- Added support for new AI models in Studio, including Gemini 2.0 and custom fine-tuned options.
- Introduced Boards filtering by status (Pending, Approved, Live, Paused, Rejected, Retired).
- New integrations with Google Drive and ChatGPT for direct exports from Library.

## Improvements

- Enhanced search in Library to find items by aspect ratio (e.g., `16:9`) or keywords like "aura-hero".
- Optimized performance for large collections, reducing load times by 40% for 1,000+ items.
- Updated UI in Studio with drag-and-drop for Elements reorganization.

## Bug Fixes

- Fixed download issues for high-resolution stills and videos.
- Resolved sync errors when posting approved items to external platforms.
- Corrected status updates not reflecting in real-time for shared Boards.

</Update>

## Upgrade Instructions

Follow these steps to upgrade BosOn to the latest version safely.

<Steps>
  <Step title="Backup Your Data" icon="database">

    Export your Library items and Boards.

    ```bash
    boson-cli export --library --boards --output=/path/to/backup
    ```

  </Step>
  <Step title="Update Configuration" icon="settings">

    Update your config file with the new format.

    <CodeGroup tabs="JSON,YAML">
      ```json
      {
        "apiUrl": "https://api.example.com",
        "libraryPath": "/path/to/library",
        "defaultModels": ["higgsfield", "custom"]
      }
      ```
      ```yaml
      apiUrl: https://api.example.com
      libraryPath: /path/to/library
      defaultModels:
        - higgsfield
        - custom
      ```
    </CodeGroup>

  </Step>
  <Step title="Run the Update" icon="download">

    Install the latest version and migrate.

    ```bash
    npm install boson@latest
    boson migrate --from=v1.1.0
    ```

  </Step>
  <Step title="Verify" icon="check-circle">

    Check your Library and Studio for any issues.

  </Step>
</Steps>
